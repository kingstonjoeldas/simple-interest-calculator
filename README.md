# Simple Interest Calculator

This project calculates simple interest from a principal amount, a rate of interest, and a time period.

## Formula

Simple Interest = (P x R x T) / 100

- P = Principal amount
- R = Rate of interest per year (%)
- T = Time period (years)

## Example

Principal = 5000, Rate = 5%, Time = 2 years
Simple Interest = (5000 x 5 x 2) / 100 = 500

## How to use

1. Run the program.
2. Enter the principal amount.
3. Enter the rate of interest.
4. Enter the time period.
5. The program shows the simple interest.
